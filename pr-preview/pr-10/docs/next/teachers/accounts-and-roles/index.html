Accounts and roles

Who can do this

Anyone can register. What you can do afterwards depends on your role, so read the roles table before planning a class.

Register​

Open designer.leia.ovh/register. The same account is used by the Designer and the Workbench.

#Field or buttonWhat it does
1EmailYour login name. The Workbench and the Designer identify you by it, and students see it nowhere.
2PasswordAt least 6 characters.
3Confirm passwordMust match the password. The eye icon shows or hides both fields at once.
4VerificationA Cloudflare check that runs by itself. The Register button stays disabled until it passes.
5RegisterCreates the account and sends you to the login page.
6Log inLink for people who already have an account.

The form validates in this order. Empty required fields, then the email format, then the password length, then the match between the two passwords, then the verification check. A new account always receives the instructor role.

Log in​

Open designer.leia.ovh/login.

#Field or buttonWhat it does
1EmailThe address you registered with.
2PasswordYour password. The eye icon reveals it.
3VerificationThe same automatic Cloudflare check as in the register form.
4LoginSigns you in and opens the LEIA library.
5RegisterLink to the register form.

If you open the Designer while a session is still valid you land directly in the library. The session is refreshed every five minutes and every time the browser window regains focus. When the server rejects an expired session you are sent back to the login page, and when it rejects your role you see an Access Denied page with a Go to Home button and a Switch Account button that logs you out.

The Workbench has its own sign-in page at workbench.leia.ovh/login with the same email and password. It only admits the advanced and admin roles. An instructor sees the message "Instructors cannot access workbench administration." The student entrance of the Workbench is a different page and needs no account. See What students see.

Find your way around the Designer​

#ItemWhere it goes
1LEIA libraryThe home page. Search, test and design LEIAs. See The LEIA library.
2Continue draftsLEIAs you started designing and did not finish. See Drafts.
3DesignStarts a new LEIA. See Create a LEIA with the AI assistant.
4ActivitiesGroups of LEIAs ready to be published. Only visible to the advanced and admin roles. See Activities.
5ProfileYour email, your role and the password change form.
6API keysLanguage model keys. See API keys and models.
7LogoutEnds the session.
8Account menuThe avatar at the top right. It repeats Profile and Logout and, for administrators, adds Manage labels.

Administrators also see a Users entry in the sidebar that opens the user management page.

Your profile​

#ItemWhat it does
1Email AddressThe address you log in with.
2EditOpens a field to type a new address. Save applies it, Cancel discards it. The new address must be different from the current one.
3RoleYour current role. Only an administrator can change it.
4ChangeOpens the password form with Current Password, New Password (at least 6 characters) and Confirm New Password.

The My LEIAs link currently returns to the library.

Instructors and the AI assistant

The AI assistant always writes a new behaviour together with the persona and the problem. Because only the advanced and admin roles may create behaviours, an instructor account gets an error on Finish LEIA when the behaviour is new. Instructors can still design LEIAs by starting from an existing one with Design from this and leaving the behaviour untouched. The quick start follows that path.

Everything you create is private by default. Other users only see it once an administrator publishes it. Write to the LEIA team at team@leia.ovh to ask for the advanced role or to have a LEIA published.

Log out​

Use Logout at the bottom of the sidebar or in the account menu. The Workbench has its own Logout entry under Admin in its sidebar.
