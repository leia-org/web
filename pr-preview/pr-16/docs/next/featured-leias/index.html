Featured LEIAs

The featured LEIAs are the nine LEIAs the LEIA team maintains as examples of what the platform can do. Each one is published in the LEIA library of the Designer with the label featured, and each one has two public demo activities in the Workbench: one where you type and one where you talk.

Every page of this section describes one LEIA: who you talk to, what you have to do, how the LEIA behaves, the instructions students see and the links to try it in text and in voice.

How the demo links work

The links below open the Workbench with the activity code and a demo identity already filled in. Press Start session, read the instructions and press Continue Task. Every visit creates a fresh throwaway student, so you can start over as many times as you like and nothing you do is tied to you. The Try typing box under the chat suggests a good first message.

The voice demos need a microphone. The chat is replaced by a stage with the character's avatar: unmute, speak, and the LEIA answers aloud. The microphone is unmuted when you close the instructions.

What all of them share​

  • One LEIA, one activity. Each demo is a replication with a single LEIA, so the link always opens the same character. The text and voice demos of a LEIA share the same persona, problem and behaviour; only the Workbench settings differ.
  • Instructions first. The activity opens with an Instructions dialog that holds the problem description quoted on each page. The Instructions button in the header reopens it.
  • A deliverable at the end. Except for the game, every demo asks for a solution when you press the main button in the header (Go to Editor or Send Solution) and grades it with the language model. The pages say what each LEIA expects.
  • Voice is the Luke mode. The voice demos use the Luke audio mode described in LEIA settings. The coding LEIAs keep their code editor next to the avatar.

Use a featured LEIA in your own course​

Featured LEIAs are public, so every teacher account can build on them:

  1. Open the LEIA library in the Designer and set Label to featured.
  2. Press Quick replication on a row to get your own activity with your own code, or Design from this to change the character or the exercise first. The quick start tutorial walks through the second path.
  3. In the Workbench, adjust the replication settings and the LEIA settings: model, voice, automatic evaluation.

The coding LEIAs need an OpenAI model, because the code editor relies on tool calls. See the code editor widget.
