## What We Do

- Product design and learning flow definition.
- Backend and frontend development.
- Documentation, versioned content, and maintenance.
- Support for educational simulations and AI-assisted scenarios.

## About This Project

LEIA is a platform that helps instructors design interactive simulations and students practice realistic scenarios with AI support.

If you want to contribute or report an issue, start by reviewing the project documentation and the relevant versioned section for your use case.
